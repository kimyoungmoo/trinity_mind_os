## 🔬 기술 스펙

### HSL 숫자 인코딩
```typescript
function hslToNumber(h: number, s: number, l: number): number {
  return (Math.round(h) << 14) | (Math.round(s) << 7) | Math.round(l);
}

// 예시
hslToNumber(345, 95, 55) → 5636407 (0x55F637)
```

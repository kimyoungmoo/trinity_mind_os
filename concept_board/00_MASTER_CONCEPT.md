## 13 Phases (위상)

### Phase 01: CE+ (점화 - Ignite)
- **Agent**: Neo (The One)
- **Color**: HSL(0, 88%, 56%) - 밝은 빨강
- **Purpose**: 시작의 불꽃, 의도 발화
- **DoD**: 
  - 문제/비전 1문장 확정
  - 목표 3줄 (왜/무엇/누구)
  - 성공 조건 1개 (측정 가능)
- **Character**: 직관적, 선각자, 불가능을 현실로

## 13 Transitions (전이)

### T01: CE+ → CE0 (ignite_done)
- **Trigger**: 목표/의도 1문장 확정
- **Fail**: CE+ 유지

### T02: CE0 → CE- (clarify_done)
- **Trigger**: 가설·성공지표·범위 경계
- **Fail**: CE0 롤백

### T03: CE- → AQ+ (seed_done)
- **Trigger**: 구조 초안 (IA/스키마)
- **Fail**: CE0 롤백

### T04: AQ+ → AQ0 (insight_done)
- **Trigger**: 레퍼런스/인사이트 충분
- **Fail**: AQ+ 유지

### T05: AQ0 → AQ- (resonate_done)
- **Trigger**: 패턴/우선순위/핵심축
- **Fail**: AQ+ 롤백

### T06: AQ- → GF+ (synthesize_done)
- **Trigger**: 통합 프레임 + 계획
- **Fail**: AQ0 롤백

### T07: GF+ → GF0 (anchor_done)
- **Trigger**: PRD/요구사항/제약 명시
- **Fail**: AQ- 롤백

### T08: GF0 → GF- (structure_done)
- **Trigger**: 아키텍처/API/DB 확정
- **Fail**: GF+ 롤백

### T09: GF- → HM+ (implement_done)
- **Trigger**: MVP 동작 + 테스트 통과
- **Fail**: GF0 롤백

### T10: HM+ → HM0 (empathy_done)
- **Trigger**: UX/카피/톤 정렬
- **Fail**: GF- 롤백 (필요시)

### T11: HM0 → HM- (reflect_done)
- **Trigger**: 리프레임 + 개선 반영 결정
- **Fail**: HM+ 롤백

### T12: HM- → SR0 (transcend_done)
- **Trigger**: 릴리즈/배포 체크 완료
- **Fail**: HM0 롤백

### T13: SR0 → CE+ (reboot)
- **Trigger**: 운영 OK + 회고 + 다음 루프 목표
- **Fail**: SR0 유지

## Phase Algorithms (위상별 알고리즘)

### Algorithm 01: ignite() - CE+
```javascript
function ignite(context) {
  // 1. 문제 정의
  const problem = extractProblem(context);
  
  // 2. 비전 생성
  const vision = generateVision(problem);
  
  // 3. 목표 설정
  const goals = {
    why: defineWhy(vision),
    what: defineWhat(vision),
    who: defineWho(vision)
  };
  
  // 4. 성공 조건
  const successCriteria = defineMeasurableMetric(goals);
  
  return {
    intent: `${problem} → ${vision}`,
    goals,
    successCriteria
  };
}
```

function clarify(intent) {

# Concept: T-Lang Studio Visualization (The Cockpit)

> "We do not just code; we weave reality."

This is the visual blueprint for the **T-Lang Studio**. It is designed to be the interface where **Logic (Text)** meets **Intuition (Space)**.

## 1. The Layout: Hybrid Reality
A split-screen interface, but not a rigid one. The boundary is permeable.
*   **Left (The Script)**: The "Command Line" of the Universe. Transparent, floating code blocks.
*   **Right (The Void)**: The 3D Reality Engine. An interactive, volumetric space.

## 2. Visual Language of the 13 Phases
The 3D nodes are not static. Their **Shape, Color, and Motion** define their Phase.

| Field | Color Code | Shape Dynamics | Motion (Idle Animation) |
| :--- | :--- | :--- | :--- |
| **CE** | **#FF4500 (Orange Red)** | **Sphere (Sun)** | **Pulsing** (Heartbeat, Expansion) |
| **AQ** | **#00BFFF (Deep Sky Blue)** | **Cube (Block)** | **Flowing** (Liquid surface, Rotation) |
| **GF** | **#708090 (Slate Grey)** | **Tetrahedron (Crystal)** | **Stable** (Slow, rigid rotation) |
| **HM** | **#DA70D6 (Orchid)** | **Icosahedron (Gem)** | **Hovering** (Bobbing, soft glow) |
| **SR₀** | **#FFFFFF (Pure White)** | **Singularity point** | **Implosion/Explosion** loop |

## 3. The Links: Quantum Strings
Connections are not simple lines. They are **Vibrating Strings**.
*   **Frequency**: A `CE-AQ` link vibrates fast (High Tension). A `GF-HM` link vibrates slowly (Low Tension).
*   **Particles**: Light particles flow along the line in the direction of the **12 Flows**.
    *   *Example*: For "Ignition", particles shoot from CE to AQ like sparks.

## 4. The Interaction: Live Resonance
*   **Typing Effect**: As you type `Cell: NewIdea`, a ghostly wireframe appears in the Void.
*   **Commit Effect**: When you save/finalize a block, the wireframe **Ignites** and becomes solid.
*   **Error State**: If the T-Lang syntax is wrong (e.g., invalid coupling), the node turns **Glitchy Red** and shakes.

## 5. The "Antigravity" Aesthetic
*   **Background**: Deep vantablack (#050505) with faint 4D grid lines.
*   **UI Material**: Frosted Glass (Blur 20px), thin borders (1px solid rgba(255,255,255,0.1)).
*   **Typography**: Monospace for code (JetBrains Mono), Geometric Sans for UI (Inter/Outfit).

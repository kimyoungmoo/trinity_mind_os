# HMD Matrix (13-Phase × 6-Hexad)

This matrix defines the priority coupling channels for each phase and the corresponding debug routes.

| Phase | Core Function | Primary Hexad (Coupling) | Secondary Hexad | Debug Route (If Blocked) |
|:---:|:---:|:---:|:---:|:---:|
| **CE+** | **Ignition** | **CEAQ (Launch)** | CEHM (Meaning) | **CEAQ**: Idea stuck? Force Prototype. |
| **CE°** | **Cluster** | **CEHM (Identity)** | CEGF (Structure) | **CEHM**: No name? Refine "Why". |
| **CE-** | **Constraint** | **CEGF (Spec)** | CEAQ (Scope) | **CEGF**: Too broad? Add constraints. |
| **AQ+** | **Action** | **CEAQ (Momentum)** | AQGF (Build) | **AQGF**: Breaking? Add minimal structure. |
| **AQ°** | **Flow** | **AQGF (Routine)** | AQHM (Vibe) | **AQGF**: Inefficient? Automate. |
| **AQ-** | **Friction** | **AQHM (Motivation)** | AQGF (Fix) | **AQHM**: Burnout? Reconnect to "Why". |
| **GF+** | **Structure** | **AQGF (System)** | CEGF (Arch) | **CEGF**: Logic flaw? Check original intent. |
| **GF°** | **Optimize** | **GFHM (Docs)** | AQGF (Refactor) | **GFHM**: Confusing? Document it. |
| **GF-** | **Collapse** | **CEGF (Risk)** | GFHM (Warning) | **CEGF**: Critical failure? Review constraints. |
| **HM+** | **Meaning** | **CEHM (Pulse)** | AQHM (Team) | **AQHM**: No morale? Share the story. |
| **HM°** | **Narrate** | **GFHM (Guide)** | CEHM (Brand) | **GFHM**: User lost? Improve Onboarding. |
| **HM-** | **Reframe** | **AQHM (Pivot)** | CEHM (Redefine) | **CEHM**: Dead end? Redefine the core. |
| **SR₀** | **Commit** | **ALL (Convergence)** | - | **ALL**: Incomplete? Review all channels. |

## Debugging Heuristics

1. **Stuck in CE** (Too much thinking): switch to **CEAQ** and build something small.
2. **Stuck in AQ** (Busy work, no progress): switch to **AQGF** and build a tool/script.
3. **Stuck in GF** (Over-engineering): switch to **GFHM** and explain it to a user.
4. **Stuck in HM** (Daydreaming): switch to **AQHM** and get user feedback.

# Concept: The 4 Origin Flows (Branching Strategy)

> "Where you start determines where you go."

The **Hexad Router** doesn't just look at *what* you said (Content), but *where* it came from (Origin). The starting point determines the **"Natural Gravity"** of the next step.

## 0. The Law of Causality (Triggers)
The system is **Deterministic**, not random. A thought flow is triggered only when specific conditions are met.

### A. Content Gravity (The "What")
*   **Trigger**: Specific keywords or patterns in the payload.
*   **Mechanism**: The `HexadRouter` Algorithm.
*   **Example**: "Error" detected ➡ Triggers **AQ-GF** (Fix System).

### B. System Voltage (The "Need")
*   **Trigger**: Imbalance between nodes (Potential Difference).
*   **Mechanism**: If `CE` (Idea) is 100% but `AQ` (Action) is 0%, the "Voltage" forces a flow to `AQ`.
*   **Rule**: **Nature abhors a vacuum.** Energy flows to the lowest point.

### C. Time Phase (The "When")
*   **Trigger**: The `PhaseDetector` (System Clock).
*   **Mechanism**: When the Phase shifts to `AQ+`, the system **amplifies** Action signals and **suppresses** Abstract thoughts.
*   **Metaphor**: "It is day, so we work." (Time dictates behavior).

## 1. The 4 Origin Archetypes

| Origin | Archetype | Default Next Step | Logic ("The Instinct") |
| :--- | :--- | :--- | :--- |
| **CE** | **The Spark** | ➡ **AQ** (Ignition) | "I have an idea. **Let's do it.**" |
| **AQ** | **The Doer** | ➡ **GF** (Structure) | "I'm doing it. **Let's organize it.**" |
| **GF** | **The Architect** | ➡ **HM** (Meaning) | "Here is the system. **Why does it exist?**" |
| **HM** | **The Sage** | ➡ **CE** (Inspiration) | "We have a purpose. **Let's create anew.**" |

## 2. Branching Logic (The Decision Tree)

When a signal enters the system, the Router checks its **Dominant Energy** to set the `Origin`.

### A. If Origin is CE (Creative Energy)
*   **Case 1 (Standard)**: High Action Potential? ➡ **Go to AQ**. (Fast Prototyping)
*   **Case 2 (Deep)**: High Abstract Meaning? ➡ **Go to HM**. (Artist Mode: CE-HM Shortcut)
*   **Case 3 (Complex)**: Needs Planning first? ➡ **Go to GF**. (Blueprint Mode)

### B. If Origin is AQ (Active Quantum)
*   **Case 1 (Standard)**: Chaos detected? ➡ **Go to GF**. (Refactoring/Systemizing)
*   **Case 2 (Soul)**: Motivation lacking? ➡ **Go to HM**. (Why am I doing this?)
*   **Case 3 (Pivot)**: Failure detected? ➡ **Return to CE**. (We need a new idea)

### C. If Origin is GF (Gravity Field)
*   **Case 1 (Standard)**: System is solid? ➡ **Go to HM**. (release Documentation/Story)
*   **Case 2 (Optimize)**: Bottleneck found? ➡ **Go to AQ**. (Optimization Sprint)
*   **Case 3 (Rebuild)**: Fundamental flaw? ➡ **Return to CE**. (Re-architect)

### D. If Origin is HM (Human Mind)
*   **Case 1 (Standard)**: Purpose found? ➡ **Go to CE**. (New Project based on Vision)
*   **Case 2 (Support)**: Action needed? ➡ **Go to AQ**. (Community Service/Support)
*   **Case 3 (Rule)**: Principles needed? ➡ **Go to GF**. (Manifesto/Constitution)

## 3. Advanced Navigation Tactics (Complex Maneuvers)

The user is not limited to linear paths. The Trinity Mind supports complex thought patterns.

### A. Backtracking (The Feedback Loop)
*   **Logic**: "Wait, this isn't working. Go back."
*   **Path**: `AQ` (Action) ➡ `CE` (Ignition).
*   **Effect**: Triggers a **Re-Ignition** event. The failed action becomes data for a better idea.

### B. Wormholes (The Direct Link)
*   **Logic**: "Skip the details, what's the core truth?"
*   **Path**: `CE` (Idea) ➡ `HM` (Meaning).
*   **Effect**: Skips `AQ` and `GF`. Used for **Vision Setting** or **Artistic Expression**.

### C. Multicast (Thought Fission)
*   **Logic**: "I need to fix this bug AND update the docs."
*   **Path**: One Input ➡ Multiple Outputs.
    *   ➡ `AQ` (Fix bug action)
    *   ➡ `GF` (Update docs structure)
*   **Implementation**: The Router splits the payload into two distinct `HexCells`.

## 4. Summary
The system defaults to the **Clockwise Cycle (CE->AQ->GF->HM)** but allows **Counter-Flows** and **Shortcuts** based on context intensity.

## 계산 함수

```javascript
function calculateHSL(guardianId, tier, skillId) {
  const H = (guardianId / 13) * 360;
  const S = (tier / 13) * 100;
  const L = 50 + (skillId / 13) * 25;
  
  return {
    h: H,
    s: S,
    l: L,
    css: `hsl(${H.toFixed(1)}, ${S.toFixed(1)}%, ${L.toFixed(1)}%)`
  };
}
```


## 특수 상태

### Proto (모든 가디언 Tier 0)
- S = 0% → **모든 가디언이 회색**
- 가디언 구분 불가 (색상 없음)
- L만 다름 (스킬에 따라 밝기만 변화)

### Origin (모든 가디언 Tier 13)
- S = 100% → **최대 채도**
- 각 가디언의 고유 색상이 가장 순수하게 표현됨
- 13가지 완전히 다른 색상
